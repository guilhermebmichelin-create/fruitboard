# Research records

This directory holds reviewed, bounded proof-of-concept plans and results for
architecture gates such as parser compatibility, DriveFS behavior, file
identity, packaging, and real-device PWA behavior.

Research records must state the question, environment, inputs, observed result,
limitations, and resulting decision. They are documentation, not production
features.

Never add personal projects, credentials, personal paths, raw diagnostic dumps,
or copyrighted fixtures here. FLPs, presets, and audio remain ignored by
default; an approved public or purpose-built fixture requires a dedicated PR,
provenance/license entry, checksum, and privacy review.
