## Observation and privacy procedure

1. Pin the matching executable hash and approved F24 source hash. Confirm an
   unlocked desktop, no existing FL process and an exclusively owned synthetic
   session. Send input only after checking the owned foreground/window point.
2. Register every actual GUI value and channel owner before save-byte inspection.
   Save each original privately and pin its hash. Do not play the pattern or
   load audio/plugins. Failed authoring/focus attempts stay retained and do not
   count as passes.
3. Inventory sanitation changes narrowly; preserve every note/declaration byte.
   Reopen each sanitized candidate in the matching application without saving
   inspection edits and verify the same fields again. If a target cannot be
   authored or independently checked, mark it not qualified.
4. Use the existing bounded observer and hash-pinned comparator after GUI
   registration. Its positional comparison requires equal record cardinality;
   do not align a one-note baseline with a three-note case. Inspect each new
   layout independently and compare only genuinely corresponding controlled
   variants. Numeric tooling still reports `musicalFieldsQualified: false`.
5. Record exact candidate hashes, approved source provenance, actual GUI facts,
   raw records/declarations and complete sanitation differences. Scan for
   registration/account/path/email/audio/image data and retain raw evidence
   privately. Existing approved fixture bytes must remain unchanged.
6. Prepare a concrete exact-byte expectation/privacy packet for the owner before
   any new FLP bytes enter Git. Starting this experiment does not approve public
   fixture publication. Promote runtime support only in a later reviewed slice.

Sampled values do not prove every intervening value, general octave/velocity
conversion or universal format compatibility. Saved channel IDs are local to
each file. A deletion that renumbers channels supplies no sparse-ID evidence.
Preserve ordinary per-pattern completeness and explicit refusal of an unknown
record; never drop it and show a partial sequence as complete.
