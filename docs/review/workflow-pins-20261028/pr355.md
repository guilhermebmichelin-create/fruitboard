# Keep future CodeQL updates together

PR354 updates both CodeQL action steps to the same reviewed v4.39.1 commit.
PR355 follows it by grouping `github/codeql-action/*` Dependabot updates.
The original separate init/analyze proposals could not pass the unchanged
matching-version rule. Future updates should arrive together instead.

The policy regression test checks that the GitHub Actions ecosystem retains
this group. The strict approved-SHA allowlist and matching-version test stay
intact, as do workflow permissions, triggers, secrets isolation and audit gates.
This changes no application behavior, data, release or phase acceptance.
